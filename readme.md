# PGL-Navigation

Aplicación móvil desarrollada con **Expo Router** que gestiona la navegación mediante un **Drawer** y **Tabs**, integrando varias pantallas construidas a lo largo del curso.

## ¿Qué hace la aplicación?

La app presenta un portfolio personal con navegación lateral (Drawer) que da acceso a:

- **Bienvenida** – Pantalla inicial con imagen, mensaje y botón para ir al portfolio.
- **Portfolio** – Sección con dos pestañas (Tabs): lista de hobbies y código QR del repositorio. Ambas comparten una cabecera con imagen y descripción personal.
- **Lista de Recuento** – Pantalla para añadir elementos y llevar un recuento de cuántas veces aparecen.
